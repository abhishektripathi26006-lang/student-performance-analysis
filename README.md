📊 Student Performance Analysis

A Python-based data analysis project that analyzes student academic performance using Pandas, NumPy, and Matplotlib.

The project explores students' marks, subject-wise performance, attendance, and overall averages to generate useful insights through data analysis and visualization.

🚀 Features

- 📈 Calculates individual student average marks
- 📚 Calculates subject-wise average marks
- 🏆 Finds the Top 5 performing students
- 🧮 Performs basic statistical analysis
- 📊 Generates 5 different visualizations
- 📝 Analyzes the relationship between attendance and performance
- 📉 Shows Maths marks distribution

🛠️ Tech Stack

- Python
- Pandas — Data cleaning and analysis
- NumPy — Numerical calculations
- Matplotlib — Data visualization

📊 Charts Generated

The project generates the following charts:

1. Student Average — Average marks of each student
2. Subject Average — Average marks across different subjects
3. Attendance Impact — Attendance vs. student performance
4. Top 5 Students — Performance comparison of the top 5 students
5. Maths Distribution — Distribution of Maths marks
